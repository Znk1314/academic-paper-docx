# Specific Aims（正面示例：缺口 + 可证伪假设 + 平行目标 + 可行性证据）

脓毒症在早期可治，但床旁评分报得晚且报警过多，临床难以区分真实告警与噪声。

**本申请的目标**是交付一个告警经过校准、并且可跨中心迁移的早期预警模型。

我们的中心假设是：把连续生命体征趋势与常规化验融合，可在不提高误报率的前提下把恶化检出提前数小时。该假设基于本团队单中心前期结果（图 1，n=812，AUC 0.88）。

Aim 1：确定回顾性 ICU 数据上"检出—误报"的可行边界，并给出逼近该边界的模型；校准用 proper scoring rule 量化。

Aim 2：判断在生命体征趋势之外加入常规化验能否改善早期检出，以及对哪些患者亚组有益或有害。

Aim 3：量化告警校准在跨中心时的迁移性，采用一家前瞻性留出医院验证。

三个 aim 相互独立，各自都能产出可用的结果。预期影响：一个经过校准、可迁移的早期预警工具，已与两家合作医院签署数据使用协议（支持信随附）。
