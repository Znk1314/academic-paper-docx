# 前置部分顺序：封面 → 摘要 → 目录 还是 封面 → 目录 → 摘要？

**结论：国家标准与主流高校规范都是"摘要页在目次页之前"。**

即：封面 → 题名页 → 原创性声明／使用授权 → 致谢 → **摘要页（中→英）** → 序言／前言 → **目次页** → 插图和附表清单 → 正文。

本 skill 的默认顺序就是这个；少数学校模板要求"目录在前"时，用 `"front_order": "toc-first"` 切换。

## 一、国家标准怎么说

### GB/T 7713.1—2025《信息与文献 编写规则 第 1 部分：学位论文》

（代替 GB/T 7713.1—2006；2025 年版）

**附录 A（规范性）表 A.1 学位论文的构成要素**，前置部分按下列**行序**排列：

| 顺序 | 组成 | 必备性 |
|---|---|---|
| 1 | 封面 | 可选 |
| 2 | 封二 | 可选 |
| 3 | 题名页 | 必备 |
| 4 | 英文题名页 | 可选 |
| 5 | 勘误页 | 有则必备 |
| 6 | 原创性声明 | 必备 |
| 7 | 使用授权说明 | 必备 |
| 8 | 致谢 | 有则必备 |
| 9 | **摘要页** | **必备** |
| 10 | 序言或前言 | 有则必备 |
| 11 | **目次页** | **必备** |
| 12 | 插图和附表清单 | 有则必备 |
| 13 | 缩写和符号清单 | 有则必备 |
| 14 | 术语表 | 有则必备 |

**摘要页（第 9 行）在目次页（第 11 行）之前。**

旁证两条：

- **5.2.8 致谢**："致谢可单独成页，**置于摘要页前**" —— 说明"摘要页"是一个有固定位置的锚点。
- **附录 E（目次页编排示例）**：目次条目按 `序言(前言) …… Ⅰ`、`**摘要 …… Ⅱ**`、`**目次 …… Ⅳ**`、
  `1 引言 …… 1` 排列 —— 目次里"摘要"排在"目次"之前，且前置部分用罗马数字页码。
- **5.2.9 摘要页**："为便于国际交流，宜有英文摘要，**另起一页，置于中文摘要页的后面**。"
  → 中文摘要 → 英文摘要（各自独立成页）→ 目次。

### GB/T 7713.2—2022《学术论文编写规则》

期刊论文**没有目录**这一构成要素（目录是学位论文、研究报告的前置部分），
所以"目录放哪"不属于 7713.2 的管辖范围。

## 二、高校规范实例（四份，结论一致）

| 来源 | 原文顺序 |
|---|---|
| **中国科学院**（上海营养与健康所研究生学位论文撰写规范） | 封面、原创性声明及授权使用声明、**摘要、目录**、正文、参考文献、附录、致谢… |
| **武汉科技大学**（本科毕业设计（论文）规范 第二条） | 封面、**中文摘要、英文摘要、目录**、正文、参考文献、致谢、附录… |
| **华东师范大学**（博士、硕士学位论文基本格式要求） | 前置部分：1 封面 … 5 **摘要及关键词页** 6 **目录页** 7 插图和附表页清单 |
| **河北工程大学**（博士学位论文撰写规范） | 前言中列出"摘要 → 目录 → 正文 → 参考文献 → 附录" |

（WUST 那份还特别写明是**本科毕业设计**，与本 skill 的"毕业设计"场景完全对口。）

## 三、为什么会有"目录在前"的印象

1. **出版物与专著**：图书的目次（Contents）确实紧跟书名页，摘要（如果有）往往在后面或是内容提要。
   但那是"出版物"，不是"学位论文"。
2. **部分课程报告／竞赛模板**：没有强制国标，按指导老师偏好，目录前置也常见。
3. **英文 thesis 习惯不一**：有的学校 Title → Abstract → Acknowledgments → Table of Contents，
   也有 Title → TOC → Abstract。国内规范反而统一。

所以：**"目录在摘要后"不是错误，是规范要求**；只有当你学校模板明确写了"目录在前"时才需要反过来。

## 四、本 skill 的实现

默认（符合国标）：

```
封面 → 摘要（中文，独立成页）→ Abstract（独立成页）→ 目录 → 正文
```

页序实测（示例文档 11 页）：

| 页 | 内容 |
|---|---|
| 1 | 封面 |
| 2 | 摘　要 |
| 3 | Abstract |
| 4 | 目　录 |
| 5+ | 正文 |

需要"目录在前"时，内容模型里加一行：

```jsonc
{ "front_order": "toc-first", ... }
```

`apd qa` 会检查这一项：

```
OK   前置部分顺序：摘要页在目次页之前（GB/T 7713.1—2025 表 A.1）
```

判为 **WARN** 而非 FAIL —— 因为少数校规确实要求目录在前，工具不该替学校做决定。

## 五、还能再严格的两点（按需开启）

| 项目 | 国标要求 | 现状 |
|---|---|---|
| 前置部分页码用罗马数字 | 附录 E 示例：Ⅰ、Ⅱ、Ⅳ | 目前全篇阿拉伯数字连续编号（`第 X 页 / 共 Y 页`） |
| 目次中列出"摘要"条目 | 附录 E 示例含 `摘要 …… Ⅱ` | 默认摘要不进目录；`"toc_include_front_matter": true` 可开启 |

这两条属于"锦上添花"，如果你的学校模板明确要求，我可以把前置部分改成
罗马数字分节页码（sectPr + `w:pgNumType`），正文重新从 1 开始。
