# 论文图表规范（核对版）

> 依据：**GB/T 7713.2—2022《学术论文编写规则》**（2022-12-30 发布，2023-07-01 实施，现行；
> [国家标准全文公开系统](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=0B963916637B8F34B295FCF4A51A1BE5)），
> 叠加中英文期刊的通行实践。
>
> 核对结论见 §4：**GB/T 7713.2 管"有无与结构"，不管磅值、dpi 这类具体数值**；
> 后者是期刊惯例，本 skill 给出默认值并允许覆盖。

## 1. 总体原则（四条基线）

1. **自明性**：脱离正文也能独立读懂（轴、单位、图例、统计标注齐全）。
2. **必要性**：不用图表重复正文已完整陈述的数据（规范 §10.7 同理）。
3. **一致性**：同类图表的字体、字号、线宽、符号风格全篇统一。
4. **数据墨水比**：去掉 3D、投影、装饰边框；网格淡化或移除；视觉面积留给数据。

## 2. 图

### 2.1 题注与编号
- 按正文出现顺序连续编号：`图1`、`图2`；**图题在图下方居中**。
- 图题 = 图号 + 图名；简短准确，**不要用完整句陈述结论**。
- 分图号 `(a)(b)(c)`，置于各分图左下/左上角（本 skill：左上，`panel` 字段）。
- 中英对照：中文常用黑体/宋体加粗，英文 Times New Roman，字号比正文小一号。

### 2.2 坐标轴
- 轴线为实线，刻度清晰；**纵坐标标目自下而上，横坐标从左到右**。
- 标目必须含"量 + 单位"，形式 `量符号/单位`，如 `t/s`、`c/(mol·L⁻¹)`；
  **变量斜体、单位正体**（本 skill 用 mathtext 自动处理）。
- 轴线结束在刻度处，不外延；刻度间隔取 2、5 的倍数。
- 柱状图 y 轴原则上从 0 起；确需截断必须图注说明。

### 2.3 图例与编码
- 图例放图内空白处（右上或数据不遮挡处）。
- **颜色之外必须有第二种区分手段**：实线/虚线/点线 + 圆/三角/方形标记
  （本 skill 自动按系列分配，见 `palette.serie_style()`）。

### 2.4 误差线与统计
- 展示均值必须同时给变异信息；图注**明确写出** SD / SEM / 95% CI。
- 组间差异用 `*/#/△` 标注，图注给出对应 P 值与比较对象。
- 做过对数/归一化/百分比变换的，图注要注明。

### 2.5 分辨率与格式
- 线条图（坐标图、曲线、柱图）：≥1000 dpi，或提供 PDF/EPS/SVG 矢量。
- 连续色调图（照片、切片、电泳）：≥300 dpi，建议 600 dpi 以上。
- 提供可编辑源文件；照片图加比例尺并注明染色与放大倍数。

### 2.6 版面尺寸
- 半栏 ≤75 mm，通栏 ≤160 mm；**按目标尺寸设计字号线宽**，不要靠插入后缩放。

## 3. 表

### 3.1 三线表
- 只保留**顶线、栏目线、底线**，不画竖线，表身不画横线。
- 顶/底线较粗（常 1.5 磅），栏目线较细（0.5—0.75 磅）。
- 四要素：表序与表题、表头、表身、表注。

### 3.2 题注与编号
- 按正文顺序 `表1`、`表2`；**表题在表上方居中**。
- 中英对照要求同图题。

### 3.3 表头与表身
- 每列必须有栏目名，不得空缺；物理量写 `量名称/单位`。
- **同一列小数位一致**，不足补 0；空缺用 `—`，不写"同上""〃"。
- 表内字号小于正文（中文六号宋体，西文 Times）。

### 3.4 表注
- 置于表下方，说明缩写、符号、显著性、数据来源；句末加标点。
- 非公知缩写必须在表注给全称。

## 4. 核对结论（哪些是"国标"、哪些是"惯例"）

| 说法 | 核对结果 |
|---|---|
| GB/T 7713.2—2022《学术论文编写规则》 | ✅ 存在，2022-12-30 发布、2023-07-01 实施，现行（标准号、名称、日期已从国家标准全文公开系统核对） |
| "三线表、图题在下表题在上、数字修约一致、空缺用破折号、量/单位" | ✅ 属 GB/T 7713.2 的规定范围 |
| "顶线 1.5 磅、栏目线 0.5—0.75 磅" | ⚠️ **国标不规定磅值**，这是期刊排版惯例。本 skill 取 1.5 / 0.75 并允许 `--spec` 覆盖 |
| "线条图 ≥1000 dpi、照片 ≥300 dpi" | ⚠️ 惯例（各刊 600—1200 不等）。本 skill 默认 1000，QA 底线 600 |
| "半栏 75 mm、通栏 160 mm" | ⚠️ 中文期刊惯例；Nature 单栏 89、双栏 183。已做成可配 |
| "表格 1.5 磅 + 0.75 磅、图题字号比正文小一号" | ⚠️ 惯例，按目标期刊投稿须知为准 |

**结论**：这套要求**整体准确、可直接执行**；唯一需要在文档里明确的是——
"磅值 / dpi / 毫米"属于期刊惯例而非国标强制，投稿前以目标期刊《投稿须知》为准。
本 skill 把这些都做成默认值 + 可覆盖，并在 QA 中按默认值断言。
