# 交付前人工核对清单

`scripts/qa_check.py` 能自动查出其中大部分，但下面这些**必须亲眼看 PDF 预览图**。

## 一、页面与视图

- [ ] A4 纵向，上 2.4 / 下 2.2 / 左 2.6 / 右 2.4 cm
- [ ] 封面没有页眉页脚
- [ ] 用 Word 打开时是**页面视图（打印布局）**、缩放 100%
- [ ] 没有空白页（尤其目录后、章节之间）

## 二、封面

- [ ] 顶部单位/类型 15 pt 蓝色；主标题 24 pt 深蓝；副标题 20 pt 学术蓝
- [ ] 一条 1.5 pt 学术蓝横线
- [ ] 信息表无边框，左列深蓝加粗、右列正文色
- [ ] 底部单位与日期居中、灰色
- [ ] 没有残留示例里的学校名/姓名/编号/日期

## 三、标题与目录

- [ ] 一级标题 16 pt 黑体，深蓝 `#1F3A5F`，带 0.75 pt 蓝色下边框
- [ ] 二级标题 13 pt 黑体，学术蓝 `#0072B2`
- [ ] 标题编号全文统一（`1` 或 `一、`），且与目录、正文引用一致
- [ ] 目录一页装得下，条目与正文标题完全一致，页码正确
- [ ] 目录里没有多余条目（摘要/Abstract 默认不进目录）
- [ ] 目录不是 `TOC \o "1-2"` 这样的原始域代码

## 四、正文

- [ ] 宋体 + Times New Roman，12 pt，1.5 倍行距
- [ ] 首行缩进 2 字符（不是敲空格）
- [ ] 段后 6 pt，两端对齐
- [ ] 没有大段不分段的文字；没有 `x_i` 这类裸下划线
- [ ] 没有圆形项目符号，列举统一（1）（2）（3）

## 五、三线表

- [ ] 顶线/底线 1.5 pt，表头下线 1 pt，**无竖线**
- [ ] 表题在**上**，格式 `表X 表题`，居中，9.5 pt 加粗深蓝
- [ ] 表注在**下**，以"注："开头，8.5 pt 灰色
- [ ] 表头加粗；跨页时表头重复；表行不跨页拆分
- [ ] 表格总宽不超版心（15.5 cm），没有挤成多行
- [ ] 单位写在表头括号里；百分比/缺失值/显著性在表注说明
- [ ] 模拟数据已注明"模拟数据"

## 六、图片

- [ ] 图片没有变形（等比缩放）
- [ ] 图题在**下**，`图X 图题`，9.5 pt 加粗深蓝居中
- [ ] 图注在图题下方，8.5 pt 灰色
- [ ] 图题与图片在**同一页**（图片段落 keep_with_next）
- [ ] 图片清晰不模糊（1672 px 宽 → 14 cm 约 303 dpi）
- [ ] 中文标签没有错别字（AI 生图必须逐字检查）
- [ ] 图内标题与图题不重复

## 七、公式

- [ ] 是 Word 原生 **OMML**（双击能进公式编辑器），不是图片/纯文本
- [ ] 公式居中，编号右对齐 `（1）`
- [ ] 编号连续；正文有"见式（1）"
- [ ] 变量斜体、函数名和单位正体；符号首次出现有解释
- [ ] 分式/求和/根号渲染正确，没有挤在一起

## 八、页眉页脚

- [ ] 页眉右对齐 8.5 pt 灰色，`标题 · 类型`
- [ ] 页脚居中 8 pt 灰色 `第 X 页 / 共 Y 页`
- [ ] 页码是 PAGE / NUMPAGES 域，不是手打数字
- [ ] 页脚不遮挡正文

## 九、参考文献

- [ ] GB/T 7714 格式，`[1] [2] [3]` 连续
- [ ] 9 pt，悬挂缩进 0.74 cm
- [ ] 正文引用编号与文献表一一对应；没有引用不存在的文献
- [ ] 没有虚构文献；无法确认的标 `[待补充/待核实]`

## 十、内容真实性

- [ ] 未完成的内容没写成已完成
- [ ] 未测指标标注 `[待补充/待核实]`
- [ ] 图表数据与正文表述一致，与参考文献一致
- [ ] 全文 `XXX` / `TODO` / 示例学校名 / 示例姓名 已清零
