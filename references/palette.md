# 论文插图配色规范（可执行版）

> 目标只有两个：**让数据关系被准确读取**，**让色觉障碍读者也能正确区分**。
> 这不是审美偏好，所以每条都能被 `scripts/palette.py` 断言、被 `qa_check.py` 检查。
>
> 唯一色值来源：`scripts/palette.py`。改配色 = 改这一个文件，图和 Word 文档同时生效。

## 1. 先定数据类型，再选色板类别

| 数据类型 | 含义 | 用哪个 | 代码 |
|---|---|---|---|
| **定性** | 类别之间无顺序 | Okabe-Ito（8 色）/ Tol bright | `palette.SERIES` |
| **顺序** | 数值单调变化 | viridis / cividis（色盲优化） | `palette.SEQUENTIAL` |
| **发散** | 围绕 0/对照向两侧偏离 | RdBu / vik | `palette.DIVERGENT` |

**硬性排除**：`jet` / `rainbow` / `nipy_spectral` / `hsv` 等彩虹色谱**禁止用于定量数据**
——亮度不单调，会在数据里伪造不存在的"边界"。代码里直接抛异常：

```python
palette.resolve_cmap("jet")   # ValueError: 禁止使用 'jet'
```

## 2. 定性色板：Okabe-Ito（本 skill 默认）

| # | 名称 | HEX | 建议用途 |
|---|---|---|---|
| 1 | 黑 | `#000000` | 主数据系列 / 参考线 |
| 2 | 橙 | `#E69F00` | 第二系列（与蓝对比最强） |
| 3 | 天蓝 | `#56B4E9` | 第三系列 |
| 4 | 蓝绿 | `#009E73` | 第四系列 |
| 5 | 黄 | `#F0E442` | 第五系列 |
| 6 | 蓝 | `#0072B2` | 第六系列（也是文档强调色） |
| 7 | 红紫 | `#CC79A7` | 第七系列 |
| 8 | 灰 | `#999999` | 辅助 / 背景数据 |

按顺序取前 3—5 色即可。顺序不是随便排的：**相邻两色的灰度差与色觉距离都最大**。

## 3. 色盲安全：底线要求

### 3.1 禁用组合
- **红 vs 绿**是最高频事故点（Nature 投稿指南明确要求改色）。
- 替代：蓝 vs 橙（本 skill 校验通过的最优组合，红绿色盲下距离 89）、蓝 vs 黄、紫 vs 绿、青绿 vs 品红。

### 3.2 颜色不能是唯一区分手段
必须叠加**冗余编码**：折线同时用实线/虚线/点线；散点同时用圆/三角/方形。
本 skill 自动分配（`palette.serie_style(i)`），不需要手写。

### 3.3 用经过验证的色板
`palette.TOL_BRIGHT` 提供 Paul Tol bright（7 色，色盲安全，可用于 >5 类）。
`palette.SEQUENTIAL` 提供 viridis / cividis（后者专为红绿色盲优化）。

## 4. 灰度兼容（印刷与复印场景）

- **明度差优先于色相差**：深蓝 vs 浅蓝比深绿 vs 浅绿更容易在灰度上区分。
- 判定用 **CIE L\***（感知明度，0—100），不是线性亮度：
  `palette.delta_l(a, b)` 返回 ΔL\*，**相邻灰阶差 ≥20** 视为可辨。
- 灰阶兜底：`palette.GREY_RAMP`（0 / 27 / 54 / 78 / 96 L\*，相邻 ≥17）。
- 自检命令：

```bash
python scripts/apd.py recipe new <id> --out work/figs   # 拷出配方源码后改 _kit 色板常量
```

## 5. 颜色数量的克制

- 一张图 **3—5 种主色**足够；超过 5—6 组应**拆图**或改用同色系深浅 + 图案。
- 本文档模板的彩色数 = **4**（深蓝 / 蓝 / 橙 / 绿），`qa_check` 会断言 ≤5。
- 生物医学里 >3 组后浅蓝/淡紫一类低对比配色区分度骤降，是最常见的退修原因。

## 6. 学科语义：不能反向使用

| 领域 | 约定 |
|---|---|
| 生物医学 | 红/暖 = 激活、上调；蓝/冷 = 抑制、下调 |
| 物理/工程 | 冷色 = 低能态；暖色 = 高能态 |
| 化学/材料 | 与谱图、相图惯例一致，不复用有特定指代的颜色 |

发散色板的方向必须与语义一致，**不可反向映射**（`diverging=True` 时中心值要对准 0/对照）。

## 7. 背景与对比度

- 图面白或中性色背景，不用装饰性渐变。
- 文字与背景对比度：正文 ≥4.5，图形元素 ≥3（WCAG AA）。
  代码：`palette.contrast_ratio("#262626", "#FFFFFF")`。

## 8. 文档版式色（Word 全稿）

`palette.DOC` 是 Word 文档用的角色色，与图共用同一套来源：

| 角色 | HEX | 用途 |
|---|---|---|
| `heading` | `#1F3A5F` | 一级标题（中性深蓝，**不参与数据编码**） |
| `accent` | `#0072B2` | 二级标题 / 强调线（Okabe-Ito blue） |
| `warn` | `#E69F00` | 辅助强调（Okabe-Ito orange） |
| `ok` | `#009E73` | 正向 / 完成（Okabe-Ito green） |
| `ink` | `#262626` | 正文 |
| `muted` | `#595959` | 次级说明 / 图注 / 页脚 |
| `pale` | `#EAF2FA` | 浅底提示框 |
| `rule` | `#B4C6E7` | 浅边框 |

规则：**数据色只从 `SERIES` 取；版式色不用于编码数据**；全稿彩色 ≤5；同类元素同色。

## 9. 上手流程

1. 定数据类型（定性 / 顺序 / 发散）→ 选 `SERIES` / `SEQUENTIAL` / `DIVERGENT`。
2. 画图：`python scripts/apd.py recipe new <id> --out work/figs`，改 `_kit.py` 里的色板常量
   —— 配色不合规会**直接报错**（色板外颜色、红绿色盲下同色）。
3. 看灰度版：黑白打印还能不能读？不能就加/改冗余编码。
4. 交付前跑 `python scripts/apd.py qa work/report.docx`，`[配色]` 组必须全 OK。

## 10. 可复现的自检

```python
import palette
palette.check_series(["#0072B2", "#E69F00"])        # 蓝+橙：无错，无提示
palette.check_series(["#CC79A7", "#999999"])        # 紫+灰：红绿色盲下同色 → 硬错
palette.delta_l("#E69F00", "#56B4E9")               # ΔL*≈2 → 灰度需靠线型区分
palette.cvd_distance("#0072B2", "#E69F00")          # ≈89，红绿色盲下仍可分
```

## 11. 主题色卡（设计稿配色，9 套）

用户提供的设计色卡优雅、上镜，但**它们不是"N 类分类色板"**——多数含同色系深浅
（rose6 里有三个红色阶、bluepink10 是 10 级渐变）。判断标准很清楚：

| 用途 | 需要的性质 | 同色系深浅 |
|---|---|---|
| 分类（不同处理组） | 任意两色**都要**可区分 | ❌ 是缺陷 |
| 连续/发散（热图、梯度） | 相邻色**应当**平滑过渡 | ✅ 是优点 |

所以本 skill 的处理是：**色卡注册进来 + 自动取"安全子集" + 打印实测判据**。

### 11.1 九套色卡与实测可区分度

实测口径：任意两两取 **红绿色盲（deut/prot）下的最小色距离** 与 **感知明度差 ΔL\***
（阈值：CVD ≥15 且 ΔL\* ≥15 记"安全"；≥8 记"可用（配线型/标记）"；否则"不建议"）。

| 色卡 | 色数 | 全色卡 minCVD / ΔL\* | 3 类子集 | 4 类子集 |
|---|---|---|---|---|
| `rose6` 玫瑰豆沙 | 6 | 2.3 / 1.6 | **安全** 47.0 / 28.3 | 可用 9.9 / 8.4 |
| `spectral8` 暖冷渐变（Spectral 8 级） | 8 | 6.6 / 3.6 | 可用 49.2 / 8.2 | 可用 28.0 / 8.2 |
| `minimal6` 简约六色 | 6 | 15.5 / 0.4 | 可用 34.9 / 14.8 | 不建议 28.0 / 6.7 |
| `map7` 地图灵感 | 7 | 5.5 / 1.4 | 不建议 33.0 / 6.5 | 不建议 29.9 / 6.5 |
| `medical6` 医学示意 | 6 | 8.5 / 0.8 | 不建议 29.2 / 4.8 | 不建议 29.2 / 4.8 |
| `ocean8` 全球气候 | 8 | 10.7 / 1.0 | 不建议 51.0 / 3.2 | 不建议 35.2 / 3.2 |
| `material6` 材料科学 | 6 | 20.8 / 3.2 | 不建议 52.0 / 7.1 | 不建议 28.6 / 7.1 |
| `bluepink10` 蓝粉渐变 | 10 | 3.5 / 0.3 | **安全** 59.0 / 17.0 | 不建议 47.7 / 2.1 |
| `medical2_6` 医学示意二 | 6 | 7.3 / 2.3 | 不建议 26.7 / 7.0 | 不建议 19.7 / 2.8 |

读法：`spectral8` 的 3 类子集红绿色盲下距离 49（很安全），但 ΔL\* 只有 8
（`#F46D43` 与 `#FEE08B` 亮度接近）→ **黑白打印必须靠线型/标记区分**，而我们默认就加。

### 11.2 用法

```bash
# 查看色卡与安全子集判定（不需要画图）
python scripts/apd.py palette            # 全部 9 套
python scripts/apd.py palette rose6      # 单套，列 3/4/5 类子集

# 出图时指定色卡（自动取安全子集；显式 color 优先）
python scripts/apd.py recipe list        # 同一套 Okabe-Ito 常量在 recipes/_kit.py
```

```jsonc
{"kind": "bar", "palette": "spectral8", "series": [...]}
{"kind": "heatmap", "cmap": "bluepink10", "series": [...]}   // 色卡也能当连续色图
```

### 11.3 什么时候用哪套

| 场景 | 建议 |
|---|---|
| 分类 ≤3 类、要"好看又安全" | `rose6`、`bluepink10` 的 3 类子集 |
| 需要 4—5 类、接受线型/标记兜底 | `spectral8`、`minimal6` |
| 热图 / 密度 / 梯度 | 整张色卡当色图（`cmap`），或 `cividis`（色盲最稳） |
| 要投稿到对色盲敏感的刊 | 直接 `okabe-ito`（默认，构造即安全） |

**默认仍是 Okabe-Ito**：它的 8 色是按"任意两两在色觉障碍下可分"设计的，
而设计色卡的目标是"整体协调"，两者不是一回事。色卡适合做**主题外观**
（标题线、浅底、强调色、热图渐变），分类数据优先用 Okabe-Ito 或色卡的安全子集。
