# 论文插图配色规范（可执行版）

> 目标只有两个：**让数据关系被准确读取**，**让色觉障碍读者也能正确区分**。
> 这不是审美偏好，所以每条都能被 `scripts/palette.py` 断言、被 `qa_check.py` 检查。
>
> 唯一色值来源：`scripts/palette.py`。改配色 = 改这一个文件，图和 Word 文档同时生效。

## 1. 先定数据类型，再选色板类别

| 数据类型 | 含义 | 用哪个 | 代码 |
|---|---|---|---|
| **定性** | 类别之间无顺序 | Okabe-Ito（8 色）/ Tol bright | `palette.SERIES` |
| **顺序** | 数值单调变化 | viridis / cividis（色盲优化） | `palette.SEQUENTIAL` |
| **发散** | 围绕 0/对照向两侧偏离 | RdBu / vik | `palette.DIVERGENT` |

**硬性排除**：`jet` / `rainbow` / `nipy_spectral` / `hsv` 等彩虹色谱**禁止用于定量数据**
——亮度不单调，会在数据里伪造不存在的"边界"。代码里直接抛异常：

```python
palette.resolve_cmap("jet")   # ValueError: 禁止使用 'jet'
```

## 2. 定性色板：Okabe-Ito（本 skill 默认）

| # | 名称 | HEX | 建议用途 |
|---|---|---|---|
| 1 | 黑 | `#000000` | 主数据系列 / 参考线 |
| 2 | 橙 | `#E69F00` | 第二系列（与蓝对比最强） |
| 3 | 天蓝 | `#56B4E9` | 第三系列 |
| 4 | 蓝绿 | `#009E73` | 第四系列 |
| 5 | 黄 | `#F0E442` | 第五系列 |
| 6 | 蓝 | `#0072B2` | 第六系列（也是文档强调色） |
| 7 | 红紫 | `#CC79A7` | 第七系列 |
| 8 | 灰 | `#999999` | 辅助 / 背景数据 |

按顺序取前 3—5 色即可。顺序不是随便排的：**相邻两色的灰度差与色觉距离都最大**。

## 3. 色盲安全：底线要求

### 3.1 禁用组合
- **红 vs 绿**是最高频事故点（Nature 投稿指南明确要求改色）。
- 替代：蓝 vs 橙（本 skill 校验通过的最优组合，红绿色盲下距离 89）、蓝 vs 黄、紫 vs 绿、青绿 vs 品红。

### 3.2 颜色不能是唯一区分手段
必须叠加**冗余编码**：折线同时用实线/虚线/点线；散点同时用圆/三角/方形。
本 skill 自动分配（`palette.serie_style(i)`），不需要手写。

### 3.3 用经过验证的色板
`palette.TOL_BRIGHT` 提供 Paul Tol bright（7 色，色盲安全，可用于 >5 类）。
`palette.SEQUENTIAL` 提供 viridis / cividis（后者专为红绿色盲优化）。

## 4. 灰度兼容（印刷与复印场景）

- **明度差优先于色相差**：深蓝 vs 浅蓝比深绿 vs 浅绿更容易在灰度上区分。
- 判定用 **CIE L\***（感知明度，0—100），不是线性亮度：
  `palette.delta_l(a, b)` 返回 ΔL\*，**相邻灰阶差 ≥20** 视为可辨。
- 灰阶兜底：`palette.GREY_RAMP`（0 / 27 / 54 / 78 / 96 L\*，相邻 ≥17）。
- 自检命令：

```bash
python scripts/figures.py spec.json -o fig.png --grayscale   # 同时输出灰度版
```

## 5. 颜色数量的克制

- 一张图 **3—5 种主色**足够；超过 5—6 组应**拆图**或改用同色系深浅 + 图案。
- 本文档模板的彩色数 = **4**（深蓝 / 蓝 / 橙 / 绿），`qa_check` 会断言 ≤5。
- 生物医学里 >3 组后浅蓝/淡紫一类低对比配色区分度骤降，是最常见的退修原因。

## 6. 学科语义：不能反向使用

| 领域 | 约定 |
|---|---|
| 生物医学 | 红/暖 = 激活、上调；蓝/冷 = 抑制、下调 |
| 物理/工程 | 冷色 = 低能态；暖色 = 高能态 |
| 化学/材料 | 与谱图、相图惯例一致，不复用有特定指代的颜色 |

发散色板的方向必须与语义一致，**不可反向映射**（`diverging=True` 时中心值要对准 0/对照）。

## 7. 背景与对比度

- 图面白或中性色背景，不用装饰性渐变。
- 文字与背景对比度：正文 ≥4.5，图形元素 ≥3（WCAG AA）。
  代码：`palette.contrast_ratio("#262626", "#FFFFFF")`。

## 8. 文档版式色（Word 全稿）

`palette.DOC` 是 Word 文档用的角色色，与图共用同一套来源：

| 角色 | HEX | 用途 |
|---|---|---|
| `heading` | `#1F3A5F` | 一级标题（中性深蓝，**不参与数据编码**） |
| `accent` | `#0072B2` | 二级标题 / 强调线（Okabe-Ito blue） |
| `warn` | `#E69F00` | 辅助强调（Okabe-Ito orange） |
| `ok` | `#009E73` | 正向 / 完成（Okabe-Ito green） |
| `ink` | `#262626` | 正文 |
| `muted` | `#595959` | 次级说明 / 图注 / 页脚 |
| `pale` | `#EAF2FA` | 浅底提示框 |
| `rule` | `#B4C6E7` | 浅边框 |

规则：**数据色只从 `SERIES` 取；版式色不用于编码数据**；全稿彩色 ≤5；同类元素同色。

## 9. 上手流程

1. 定数据类型（定性 / 顺序 / 发散）→ 选 `SERIES` / `SEQUENTIAL` / `DIVERGENT`。
2. 画图：`python scripts/figures.py spec.json -o fig.png --grayscale`
   —— 配色不合规会**直接报错**（色板外颜色、红绿色盲下同色）。
3. 看灰度版：黑白打印还能不能读？不能就加/改冗余编码。
4. 交付前跑 `python scripts/apd.py qa work/report.docx`，`[配色]` 组必须全 OK。

## 10. 可复现的自检

```python
import palette
palette.check_series(["#0072B2", "#E69F00"])        # 蓝+橙：无错，无提示
palette.check_series(["#CC79A7", "#999999"])        # 紫+灰：红绿色盲下同色 → 硬错
palette.delta_l("#E69F00", "#56B4E9")               # ΔL*≈2 → 灰度需靠线型区分
palette.cvd_distance("#0072B2", "#E69F00")          # ≈89，红绿色盲下仍可分
```
